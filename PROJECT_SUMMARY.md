### ✨ Landing Page Sections
1. **Hero Section**
   - Full-screen cinematic design

   - 6 AI service cards with 3D hover effects
   - Icons: AI Receptionist, Auto Booking, Complaint Agent, Social Manager, Halal Finance, Donation Agent
   - Benefit highlights for each service
   - "See example" CTAs

3. **Demo Video Section**
   - Video placeholder with play button
   - Modal for full-screen viewing
   - CTA to book personal demo

4. **Testimonials Section**
   - Carousel with 5 customer testimonials
   - Star ratings
   - Customer avatars and details
   - Statistics: 1000+ clients, 99.9% uptime, 24/7 support

5. **Pricing Section**
   - 3 pricing tiers: One-time ($2,999), Monthly ($299), Yearly ($2,999)
   - Feature comparison
   - Payment method badges

6. **Footer**
   - Service links
   - Company links (including Admin Login)
   - Contact information
   - Newsletter subscription
   - Copyright notice

  - Sapphire Blue (#06204a / hsl(215, 88%, 16%))

## 🚀 Quick Start

### Development
```bash
# Install dependencies
pnpm install

# Start dev server
pnpm run dev

# Build for production
pnpm run build

# Lint code
pnpm run lint
```

### Deployment
Choose one:
- **GitHub Pages** - Free, reliable
- **Vercel** - Easiest, automatic deployments
- **Netlify** - Great for forms and functions
- **Cloudflare Pages** - Fast, global CDN

See DEPLOYMENT.md for detailed instructions.
